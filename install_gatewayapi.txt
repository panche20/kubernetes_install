Install Gateway API CRDs:: 

kubectl apply -f https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.3.0/standard-install.yaml

Verify using : kubectl get crd | grep gateway

Expected output:
gatewayclasses.gateway.networking.k8s.io
gateways.gateway.networking.k8s.io
httproutes.gateway.networking.k8s.io
grpcroutes.gateway.networking.k8s.io
referencegrants.gateway.networking.k8s.io

Install Envoy Gateway:: 

helm install eg oci://docker.io/envoyproxy/gateway-helm \
-n envoy-gateway-system \
--create-namespace

Verify: kubectl get pods -n envoy-gateway-system

Verify GatewayClass:: 
kubectl get gatewayclass

If not present create manually:

vim gatewayclass.yaml - Enter below code in this file.

apiVersion: gateway.networking.k8s.io/v1
kind: GatewayClass
metadata:
  name: eg
spec:
  controllerName: gateway.envoyproxy.io/gatewayclass-controller

Apply using : kubectl apply -f gatewayclass.yaml
Verify using : kubectl get gatewayclass

Expected output: 

NAME   CONTROLLER                                   ACCEPTED   AGE
eg     gateway.envoyproxy.io/gatewayclass-controller True
